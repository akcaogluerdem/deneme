# deneme

Dilden bağımsız asgari proje iskeleti.

## Komutlar

```sh
make help    # hedefleri listeler
make check   # iskeletin temel dosyalarını doğrular
make clean   # üretilmiş çıktıları siler
```

## Yapı

- `README.md` — bu dosya
- `Makefile` — proje komutları
- `.gitignore` — sürüm denetimine girmeyecek dosyalar
- `.context/index.yaml` — proje bağlam dizini
