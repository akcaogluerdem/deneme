# deneme

## Hakkında

Bu depo `akcaogluerdem/deneme` projesidir. Henüz dil/çatı tespiti
yapılamadı; proje başlangıç (bootstrap) aşamasındadır.

## Başlarken

Depo kök dizininde aşağıdaki doğrulama hedefini çalıştırabilirsiniz:

```sh
make check
```

## Dizin yapısı

- `.context/` — proje bağlamı için makine tarafından okunan meta veriler.
- `Makefile` — ortak görevler için giriş noktası.

## Katkı

Değişiklik yapmadan önce `make check` komutunun geçtiğinden emin olun.
