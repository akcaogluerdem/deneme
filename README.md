# deneme

Yeni proje iskeleti. Dil ve çatı henüz seçilmedi; bu depo yalnızca
asgari proje yapısını taşır.

## Hedef

Kimliği verilen bir kaydı silen `delete <id>` komutu.

## Kullanım

```sh
make help    # hedefleri listeler
make check   # iskelet dosyalarının varlığını doğrular
```

## Yapı

- `README.md` — bu dosya
- `Makefile` — geliştirme komutları
- `.gitignore` — sürüm denetimine girmeyecek dosyalar
- `.context/index.yaml` — orkestrasyon bağlam dizini
